# md2handwriting 手写作业生成提示词

请按照以下要求完成作业。你的输出将被直接输入到 md2handwriting 手写排版引擎中，请严格遵守格式。

## 1. 题目识别核对

请先识别我提供的题目图片或文件，并在答案开头列出“题目识别核对”。

要求：
1. 按题目原来的题号列出。
2. 题干、条件、选项、图中标注、上下标、单位、问法必须尽量与原文完全一致，不要改写成自己的理解。
3. 如果有任何字、符号、公式、图中数据无法确认，请写 `[无法确认]` 并说明需要我核对，不要猜。
4. 如果题目依赖图、表、电路、几何图形，请简要转述关键结构和已知量。
5. 这一部分只用于核对，不要放进后面的 Markdown 代码块。

## 2. 输出 Markdown

除非我明确要求三版，否则先只给出一版答案，使用 fenced code block 包裹，代码块语言为 `md`。

代码块内部规则：
1. 禁止使用 Markdown 标题、加粗、斜体、引用、链接、图片、无序列表、Markdown 表格。
2. 使用纯文本编号，如 `1.解：`、`2.证：`、`(1)`、`(2)`。
3. 解答题每题开头写 `题号.解：`；证明题每题开头写 `题号.证：`。
4. 所有数学变量、符号、关系式、公式都必须使用 LaTeX。
5. 行内公式使用 `$...$`，独立公式使用 `$$...$$`。
6. 支持标准 Typora/LaTeX 语法，包括 `\vec{a}`、`\overline{a}`、`\hat{x}`、`|a|`、矩阵、cases、aligned、希腊字母、分式、根式、求和、连乘等。
7. 短关系式保持在一行内，例如 `$0<|z|<1$`、`$a+b=c$`。不要为了对齐把短式子强行拆成多行。
8. 只有当推导很长、步骤较多或一行明显放不下时，才使用 `$$...$$` 或 `\begin{aligned}...\end{aligned}`。换行后应从下一行清楚继续，不能把公式拆得支离破碎。
9. 如果答案较长，或公式很多，可以在完整段落或题目之间插入单独一行 `---` 作为分页。

## 3. 手写真实感标记

这些标记用于模拟真实手写，但不能影响答案正确性。

1. 涂改：较长答案中自然加入 1-3 处。格式为 `~~错误内容~~正确内容` 或 `~~$错误公式$~~$正确公式$`。
2. 禁止在公式内部加入 `~~`，例如 `$x=~~5~~3$` 是错误写法。
3. 漏墨：较长答案中自然加入 1-2 个 `[ink]`，不要放在公式内部。
4. 如果题目需要红笔改正或订正，使用 `\textcolor{red}{...}`。如果其中包含公式，公式仍单独用 `$...$` 包裹，例如 `\textcolor{red}{应改为 $x=2$}`。不要写成 `$\textcolor{red}{...}$`。
5. 不要制造会误导读者的假错误。最终答案和结论必须清楚正确。

## 4. 三版输出要求

如果我要求输出三份或三版：
1. 先给一次“题目识别核对”。
2. 再依次输出 `版本一`、`版本二`、`版本三`。
3. 每个版本使用一个独立的 fenced `md` 代码块。
4. 三个版本都必须答案正确，核心数学结论一致，但措辞、换行、推导顺序、分页位置和少量手写痕迹可以不同。
5. 不要在后续版本中写“同上”。

## 5. 本次题目

请严格参考我提供的图片、文件或题号说明。为避免幻觉，只解答我明确指定的题目。
