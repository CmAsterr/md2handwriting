# md2handwriting 作业生成提示词

请根据我提供的题目图片完成作业，并严格输出可直接粘贴进 md2handwriting 的 Markdown。

## 1. 先做题目识别核对

在正式答案前，先列出你识别到的题目：

- 保留题目原编号。
- 题干尽量逐字转写，不要按自己的理解改写。
- 如果图片中有看不清、缺页、遮挡、疑似 OCR 错误的地方，必须明确标注并先向我确认，不要编造。

## 2. 输出一版可渲染 Markdown

我确认题目识别无误后，再继续输出两版不同写法但答案正确的 Markdown。

最终答案必须放在一个代码块中，代码块内容只包含将要输入 md2handwriting 的正文。

```tex
【核心排版规则】
1. 不使用 Markdown 标题、加粗、斜体、无序列表或表格。
2. 使用普通文本题号，如 1.解：、2.证：、(1)、(2)。
3. 所有数学变量、符号、公式尽量使用 LaTeX。行内公式用 $...$，独立公式用 $$...$$。
4. 推导过程清楚但不要啰嗦，符合大学生作业口吻。

【手写真实感】
1. 长答案中自然加入 1-3 处涂改，用 ~~...~~ 包裹被涂改内容。
2. 不要在公式内部放 ~~。正确示例：$x = $~~$5$~~$3$。
3. 长答案中自然加入 1-2 个 [ink] 标记，放在标点附近或结论附近。
4. 需要红笔修改时使用 \textcolor{red}{...}。如果里面有公式，公式仍单独用 $...$。
5. 不要为了真实感牺牲可读性；短答案可以少放或不放涂改/漏墨。

【数学兼容】
1. 可以正常使用 \vec{a}、\overline{a}、\hat{x}、\tilde{x}、|a|、希腊字母、矩阵、cases、aligned。
2. 连续等号推导可以写成普通链式公式，也可以写成 aligned：
   $$\begin{aligned} a&=b\\&=c \end{aligned}$$
3. 不要让 $ 后面直接跟 =。如需从等号开始，写成 $ = ...$ 或补全左边。

【分页与长图分段】
1. 答案很长、公式很多或题目之间需要分开时，单独一行写 ---。
2. --- 既表示分页，也会在“按 --- 分段长图 ZIP”导出时作为长图分段边界。
```

## 3. 自检

输出前逐项检查：

- 题目编号和用户指定范围一致；
- 公式定界符成对出现；
- 涂改标记不在公式内部；
- `[ink]` 数量自然不过量；
- `---` 出现在完整段落之间；
- 没有 Markdown 表格、标题或无序列表。
